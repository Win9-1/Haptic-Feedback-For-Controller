# Haptic Feedback

Haptic Feedback is a Windows desktop app that lets you control Xbox controller vibration intensity and trigger thresholds with a modern Tron-inspired GUI.  
It uses **XInput** for instant response and **CustomTkinter** for a polished interface.

## ✨ Features
- Adjustable vibration intensity (0–100%)
- Adjustable trigger threshold (50–100%)
- Dark/Light theme toggle
- Settings saved in AppData
- Reset to defaults button
- Graceful close handling

## 🚀 Getting Started

### Prerequisites
- Windows 10/11
- Python 3.10+
- Xbox controller connected via USB
